# TC001: Проверка базового подключения ADB
Шаги:
1. Инициализировать ADB-клиент
2. Выполнить подключение к устройству
3. Проверить наличие device и serial
Ожидаемый результат:
- device не равно None
- serial не пустой

# TC002: Проверка выполнения базовой команды
Шаги:
1. Выполнить команду getprop ro.build.version.release
2. Получить версию Android
Ожидаемый результат:
- Версия Android получена
- Значение не пустое

# TC003: Проверка копирования файла
Шаги:
1. Указать путь к файлу на устройстве (/data/local/tmp/testfile.txt)
2. Указать локальный путь (file.txt)
3. Выполнить копирование
4. Проверить существование локального файла
Ожидаемый результат:
- Локальный файл создан
- Файл успешно удален после теста

# TC004: Проверка работы Logcat
Шаги:
1. Инициализировать сборщик логов
2. Запустить сбор логов
3. Подождать 5 секунд
4. Проверить существование лог-файла
5. Проверить размер лог-файла > 0
Ожидаемый результат:
- Лог-файл создан
- Размер лога больше 0
- Файл успешно удален после теста

# TC005: Проверка системных свойств
Шаги:
1. Получить свойство sys.boot_completed
2. Получить свойство ro.product.cpu.abi
Ожидаемый результат:
- sys.boot_completed = "1"
- ro.product.cpu.abi не пустое

# TC006: Проверка обработки ошибок
Шаги:
1. Попытаться выполнить несуществующую команду
2. Проверить обработку исключения
Ожидаемый результат:
- Выброшено исключение
- Система не упала

# TC007: Проверка очистки ресурсов
Шаги:
1. Выполнить очистку ресурсов
2. Подождать 32 секунды
3. Проверить qemu_process = None
Ожидаемый результат:
- qemu_process равен None
- Ресурсы успешно освобождены
